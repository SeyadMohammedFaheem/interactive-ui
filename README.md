# interactive-ui

A curated library of interactive React components, tactile micro-interactions, and fluid animations.

## ✨ Features
- **30+ Production-Grade UI Components**: Steppers, sliders, dynamic charts, OTP verification, audio players, spring-loaded sheets, and more.
- **Micro-Interactions**: Fluid gesture handling, spring physics, dynamic hover states, and haptic-style audio feedback.
- **Split-View Inspector**: Interactive parameter controls, live light/dark stage preview, and one-click code/embed export.
- **Fast & Lightweight**: Built with React, Vite, and standard Web APIs.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
